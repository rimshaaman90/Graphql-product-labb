# Product Management System using GraphQL

## Objective
To create a full-stack application using React,
Node.js, Express.js and GraphQL.

## Technologies Used
- React.js
- Node.js
- Express.js
- GraphQL
- CSS
- JavaScript

## Features
1. Display all products.
2. Add new products.
3. Fetch products using GraphQL Query.
4. Add products using GraphQL Mutation.

## Backend
The backend uses Node.js, Express and GraphQL.

## Frontend
The frontend uses React and GraphQL Request.

## How to Run

Backend:
cd graphql-lab-backend
npm install
node index.js

Frontend:
cd graphql-lab-frontend
npm install
npm start
